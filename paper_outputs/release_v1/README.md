# Compact C-MAPSS Evidence Release v1

This directory is the machine-readable compact semantic layer for the retrospective C-MAPSS portion of the manuscript. It is not the complete paper artifact and does not contain the prospectively frozen battery execution.

No C-MAPSS analysis family is confirmatory. Five training-seed levels, demonstrated small-cluster distortion, and result-informed development choices limit the evidence to finite fixed-task estimates and sensitivity diagnostics.

`release_manifest.csv` records every compact artifact's family, generator and generator hash, primary key, source hash, release hash, schema version, and row count. `metric_schema.json` fixes the LPR/ZIMLE/CMLE denominator and undefined-value contracts. `analysis_object_chronology.csv` records local provenance and identifies analyses without pre-outcome external timestamps.

The complete post-study evidence archive, including broader C-MAPSS derived evidence and the prospective battery execution, is publicly available at [OSF u76ze](https://osf.io/u76ze/), DOI [10.17605/OSF.IO/U76ZE](https://doi.org/10.17605/OSF.IO/U76ZE). Public release does not convert retrospective analyses into prospective evidence.
