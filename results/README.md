# Generated Results

This compact GitHub repository intentionally excludes trained checkpoints, per-run predictions, runtime logs, and the large stored-result tree.

The complete post-study evidence archive is publicly available at [OSF u76ze](https://osf.io/u76ze/), DOI [10.17605/OSF.IO/U76ZE](https://doi.org/10.17605/OSF.IO/U76ZE). It contains the broader C-MAPSS derived-evidence layer and the prospectively frozen battery execution artifacts, manifests, and checksums.

Local training commands populate this directory. Raw NASA C-MAPSS, N-CMAPSS, and battery source datasets are not redistributed.
